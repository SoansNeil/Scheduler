# Scheduler
A visualization of how a CPU might schedule processes based on first-come first-serve, shortest job first, round robin, and shortest remaining time first
- Add processes
- Delete an individual process and recalculate the schedule
- Visualize it through a interactable gantt chart
- See common calculations based on the gantt chart
- Understand what the calculations mean
- Compare the calculations based on scheduling process
- Visualize waiting time, turnaround time, and response time through a bar chart

## To use scheduler:
- Download project/copy https
- Terminal:
- git clone insert_project_link
- cd scheduler
- cd frontend
- open scheduler.html
